 Project Overview
This project is a basic Sentiment Analysis model built using Natural Language Processing (NLP) and Machine Learning.
It takes a user input sentence and predicts whether the sentiment is:

✅ Positive
❌ Negative

🧠 Concepts Used

Tokenization – breaking sentence into words
Stopwords Removal – removing unnecessary words
Lemmatization – converting words to base form
Vectorization – converting text into numbers
Naive Bayes Algorithm – for prediction


⚙️ Technologies Used

Python 🐍
NLTK (Natural Language Toolkit)
Scikit-learn
